# Contributing to rag-engine-alan-vo

```bash
git clone https://github.com/ALANDVO/rag-engine-alan-vo.git
cd rag-engine-alan-vo
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env
```

## Code Style
- Python 3.12+, type hints, docstrings
- TypeScript strict mode for frontend
- No hardcoded secrets

## Submitting Changes
1. Fork → feature branch → test → PR
2. Include: what changed, why, how to test

## Issues
- Steps to reproduce
- Expected vs actual
- Log output (redact keys)
